# Plan: Frontend — Persona Chat UI

Status: done
Owner: Tehila
Last updated: 2026-10-11

---

## Goal
Build the full React UI for the persona chat app — persona selection, chat window, and
message input — wired to mock data so the UI is fully testable before the backend exists.

---

## Scope

In scope:
- `App.jsx` — global state: `selectedPersona`, `messages`, `isStreaming`
- `components/PersonaSelector.jsx` + `PersonaSelector.module.scss`
- `components/ChatWindow.jsx` + `ChatWindow.module.scss`
- `components/MessageInput.jsx` + `MessageInput.module.scss`
- Mock send: `sendMessage()` returns a Promise that resolves with a mock string after 800ms —
  same signature as the real API call, so swapping to the backend later changes one line only
- `index.css` — CSS variables and global reset only (colors, fonts, body background)
- `App.module.scss` — App-level layout only

Out of scope:
- Real backend calls (replaced in the next plan)
- Streaming (simulated with a timeout for now)
- Backend, Flask, `.env`

---

## Steps

1. Install `sass`: `npm install -D sass` in `frontend/`.
2. Clean `App.jsx`, delete `App.css` — replace with `App.module.scss`.
3. Define CSS variables in `index.css`: background, surface, accent, text colors, body reset.
4. Create `components/PersonaSelector.jsx` + `PersonaSelector.module.scss` — three cards.
5. Create `components/ChatWindow.jsx` + `ChatWindow.module.scss` — message bubbles.
6. Create `components/MessageInput.jsx` + `MessageInput.module.scss` — textarea + send.
7. Wire state in `App.jsx`:
   - `sendMessage(text)` returns a Promise — appends user message, awaits the mock,
     appends assistant reply. Switching to real backend = replace the mock function only.
   - Switching persona clears `messages`.
8. Style: dark theme, readable bubbles, responsive at 375px.

---

## Validation
- [ ] Three persona cards are visible on load; clicking one highlights it.
- [ ] Typing a message and pressing Send appends it to the chat as a user bubble.
- [ ] After ~800ms a mock assistant reply appears below it.
- [ ] Send button is disabled during the fake delay.
- [ ] Switching persona clears the chat and shows the new persona as active.
- [ ] Layout looks correct at 375px width (mobile) and full desktop width.
